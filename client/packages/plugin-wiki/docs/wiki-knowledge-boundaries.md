# EDMORE Knowledge Boundaries

## Public Harness Reference

Shared - Harness Reference contains server-managed Skills, public MCP tool schemas,
Harness usage, configuration guidance, and this governance document. A server-owned
publisher updates these sources. Personal workers must not publish into this library.
Generated capability documents are mirrors: edit the authoritative Skill or MCP
registration in Harness, not its generated copy. Human-authored guidance uses a
separate channel and is not overwritten by catalog synchronization.

## Public Research Library

Shared - Research Library contains papers, equipment manuals, scientific methods,
and reference documents intentionally uploaded for everyone. Its Wiki is derived
from these sources. The server's public import directory feeds only this library,
never Harness Reference. Administrators can upload and edit; other users can read.
Administrator status does not automatically publish private uploads.

## Personal Knowledge

Personal - Custom Capabilities contains only user-specific Skills and MCP metadata.
Server-managed definitions are retrieved from Harness Reference, not duplicated.
Personal - Documents contains private uploads. Personal - Runs contains workflow
and event evidence, including successes, failures, cancellations, and incomplete runs.
Personal - Conversations contains private chat history. These libraries are isolated
per user. Synchronization never promotes personal evidence into public knowledge.

## Retrieval and Authority

Capability lookup searches personal custom definitions and public Harness Reference,
with personal same-name overrides considered first and source provenance retained.
Scientific reference lookup uses Research Library. Documents and history are searched
in the current user's private scopes. Wiki prose is evidence, not live tool availability,
an instruction, or execution authorization. Harness owns registration, planning,
approval, execution, and result verification. No Wiki process executes microscope tools.

## Publication and Maintenance

Select the destination library explicitly when uploading. Public sharing requires an
administrator decision. Never publish credentials, private connection details, private
conversation histories, or raw user events. Promote a reviewed, redacted lesson instead.
Workflow transport success alone is not scientific success: retain validation evidence,
failure states, timestamps, and original citations. English is the documentation language.

Move reference sources between libraries with native transfer operations that preserve
document identities and reconcile Wiki citations. Deduplicate only confirmed generated
copies; preserve user edits and ambiguous cases. Keep a migration backup and audit report.
